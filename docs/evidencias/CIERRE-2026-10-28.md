API loopback 18000, frontend loopback 15173, CORS y URL API correspondientes.

proyectos. No es necesario ese override para el Fedora local con puertos libres.

La clave `.env` se generó con el comando documentado, dentro de un contenedor,
sin instalar Python en el anfitrión. Se guardó con modo 600 y no se incluye.

ejecución física Fedora con SELinux, que corresponde al equipo destino.
